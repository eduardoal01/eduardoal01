## 💼 Experiência

### Estagiário de Desenvolvimento Python — CAP Promotora · *nov/2025 – atual*

Desenvolvimento full stack em Python para uma promotora de crédito *(repositórios privados)*:

- 🧩 **CRM interno de ponta a ponta** — Django + Django REST Framework, PostgreSQL e interface responsiva em Tailwind CSS, usado diariamente pelo time comercial para cadastro, acompanhamento e histórico de clientes.
- ⚙️ **Automações de margem consignada** — rotinas em Python (Poetry, estrutura modular e testes) que rodam de segunda a sexta identificando clientes elegíveis a empréstimo.
- 🕸️ **Web scraping** de portais governamentais e bancários com Selenium para coleta e atualização das bases.
- 📊 **Tratamento e análise de dados** com Pandas: padronização de bases, remoção de duplicidades e cálculo das margens que alimentam os alertas.
- 💬 **Alertas e chatbot no WhatsApp** via API WAHA containerizada com Docker/Docker Compose, entregando as oportunidades prontas para os consultores.
- 🐧 **Deploy e manutenção** em servidor Linux (VPS), com Docker e versionamento em Git.
